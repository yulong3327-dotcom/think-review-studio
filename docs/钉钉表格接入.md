# 钉钉练习表 · 下载导入审核

适用于[大纲&图谱&练习](https://alidocs.dingtalk.com/i/nodes/dQPGYqjpJYg0Xb5xIBgyzZO2Wakx1Z5N)的「练习」分表。在线版和本地版都可使用，无需管理员开通 API。

1. 在钉钉打开「练习」，下载完整 CSV；也可下载包含「练习」分表的 XLSX 工作簿。保留原表头、原列顺序和空行。
2. 网站侧栏点击「钉钉表格任务」，选择或拖入下载的文件，自动识别题目和脚本老师。选择本人后导入，或导入全部再在列表筛选老师。「未分配」可查看老师为空的任务。
3. 在完整可视化上修改讲解、公式、旁白与绘图，JSON 同步更新。每个 JSON 单元格对应一条完整任务，不拆分其内部题目。完成后标记「已通过」。
4. 再次打开「钉钉表格任务」→「导出 S 列结果」，选择审核通过的任务。
5. 「导出已回填完整表格」生成原表副本，仅更新选中任务的 S 列；「S 列结果 CSV」只包含原行号、tid、脚本老师、最终 JSON，方便负责人汇总。逐行复制或连续行复制可粘贴回原表。

## 列对应

| 列 | 标题 | 用途 |
|---|---|---|
| E | 课程名称 | 任务标题 |
| F | tid | 核对题目身份 |
| N | 脚本老师 | 选择老师任务 |
| P | 1V1-think跑出结果（参考） | 默认审核 JSON |
| S | 最终-think结果 | 唯一更新列 |

可勾选优先审核 S 列已有最终 JSON。状态、意见等保存在网站工作空间，不写入表格。

CSV 支持多行单元格、双引号转义、中文和公式反斜杠，不截断长 JSON。XLSX 导出保留其他分表、样式、图像及其他单元格内容；S 列包含公式、合并单元格或 JSON 超过 Excel 单元格长度上限时会阻止完整 XLSX 导出，可改用结果 CSV。

解析失败行显示原行号，不影响其他任务；导出保留其原内容。原文件、任务和审核进度仅保存在当前浏览器，刷新后可以继续。重新导入内容相同的原文件会保留已有审核。不同版本的文件独立关联，避免把旧行号写到新文件。更换浏览器或清除网站数据前请导出备份。

## 回到钉钉与多人汇总

导出文件不会自动修改在线原表。多人分别审核时，建议每位老师提交「S 列结果 CSV」，负责人按 tid 核对后合并到在线表格 S 列。完整表格是下载时的快照，不应整表覆盖他人的后续修改。

连续复制只允许连续行，不连续行请逐行复制。粘贴前在钉钉核对 tid、目标行及已有最终结果。只复制筛选后可见行会失去原行号，因此粘贴导入时应从 A 列起复制未筛选的完整区域；含表头起始行填 1，否则填实际起始行。
